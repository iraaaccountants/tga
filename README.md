# TGA Website

One-page corporate website for TGA Manangement Consultancy LLC.

## Preview locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript, so no build step is required.

## Files

- `index.html` — page content and structure
- `styles.css` — layout, responsive styling, and blue theme
- `script.js` — mobile menu and sticky header behavior
- `assets/` — logo, photography, client logos, and jurisdiction logos supplied in the company profile
- `robots.txt` and `sitemap.xml` — crawler guidance for the preferred domain

## Search and social metadata

The page title, description, canonical URL, Open Graph tags, social preview image, and LocalBusiness structured data are set for `https://www.tga-uae.com/`. Publish this site at that address and redirect the non-`www` version to it before relying on those URLs. The GitHub repository alone does not serve the website at that domain.

Contact details and company claims should be reviewed before a public launch.
