# Trade & IP coordination

Application and document coordination for trade administration and intellectual property matters.

## What we cover

- [Customs business code registration support](https://www.tga-uae.com/trade-ip#customs-business-code): Prepare company information for a Dubai Customs client registration request.
- [Import & export document coordination](https://www.tga-uae.com/trade-ip#import-export-documents): Help organise supporting documents for the agreed shipment or registration process.
- [Trademark application coordination](https://www.tga-uae.com/trade-ip#trademark-coordination): Organise application information and coordinate with an appropriate IP specialist.
